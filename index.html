Welcome to OpenCopiosis

Serving as a community-sourced experimental branch of Copiosis-related projects, this OpenCopiosis project is a custom build of the copiosis-rocket project running from my GitHub repository in your browser with client-side local storage. Produced to help understand how the Copiosis algorithm works. To test out the system. Make any changes or improvements where possible. And is useful for research purposes.

Start by adding a new user to begin. Then proceed through the navigation bar options, or the hamburger menu if you're on a mobile device.

A thank you to Perry Gruber, Gheric Speiginer, Michal Mauser, and the rest of the Copiosis team for their work on the Copiosis project.

Further related works of interest from third parties include a tribute site to Copiosis by Stephen Wing, Common Planet and the AYU network, and the early work that inspired it all: Invisible Hand, a book by Larry K. Mason.

The work continues.
